# Provenance

The reader modules in `src/` (`block`, `chunks`, `error`, `index`, `matcher`,
`meta`, `source`, `tombstones`, `varint`) and the tests/benchmarks fixtures in
`tests/` are vendored from **tsdb2parqtel**
(https://github.com/jatinkray/tsdb-parquet-convert), Apache-2.0, the same
maintainer as this repository. They are kept byte-compatible with the upstream
reader so fixes can be carried in either direction; `src/adapter.rs`,
`src/lib.rs`'s module list and this file are the only local additions.

Chunk decoding itself uses the MIT-licensed `tsdb-reader` crate 0.1.0
(https://github.com/zhuyanxi/tsdb-reader) as `tsdb-reader-upstream`.

## Fixtures

- `tests/fixtures/testblock` and `tests/fixtures/index_format_v1` are copied from
  the MIT-licensed `tsdb` crate v0.3.3 test data, as documented in
  `tests/fixtures/README.md`. They are test data only and never written by the
  converter.
- `tests/fixtures/native_hist` is generated by the same upstream test suite.
